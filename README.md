# Brigit debug practice (about 40 min)

Same format as the real round: a mostly finished class plus JUnit tests, with planted bugs.

1. Read the javadoc at the top of `src/LruCache.java`. That's the spec.
2. Run `./run.sh`. Most tests fail.
3. Fix `src/LruCache.java` one failing test at a time. Talk out loud as you go.
4. Bonus: write one more test of your own (e.g. capacity 1, or putting after a remove).
5. Stuck for 10+ minutes? Check `solution/LruCache.java`, or run `./run.sh solution`.

On Windows without bash, use Git Bash, or open the folder in IntelliJ with JUnit 5.
